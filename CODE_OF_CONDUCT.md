# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen:

- Trata con respeto a todas las personas.
- No se toleran acosos, insultos, discriminación ni ataques personales.
- Acepta críticas técnicas constructivas y ofrece las tuyas con empatía.
- Respeta la privacidad: no publiques direcciones, correos ni datos de otras
  personas sin permiso.

Puedes reportar conductas inapropiadas a <asterion@users.noreply.github.com>.
Las denuncias se revisarán de forma confidencial.
